# 🐶 Dog vs Cat Image Classification 🐱

### Deep Learning | MobileNetV2 | Transfer Learning | Streamlit

An end-to-end Deep Learning project that classifies images of dogs and cats using **MobileNetV2 and Transfer Learning**, achieving **98.84% test accuracy**.

The trained model is deployed as an interactive web application using Streamlit, allowing users to upload images and receive predictions.

## 🚀 Live Demo

**[Try the Live Application](https://dog-cat-classification-alok.streamlit.app/)**

**[GitHub Repository](https://github.com/Alokdubey-gif/Dog-Cat-Classification)**

## 📌 Project Overview

The objective of this project is to develop an image classification system capable of distinguishing between dogs and cats.

The project covers the complete machine learning workflow, including:

- Dataset collection and exploration
- Image preprocessing and resizing
- Transfer learning using MobileNetV2
- Model training and evaluation
- Image classification and prediction
- Deployment using Streamlit Community Cloud

## 🧠 How It Works

1. The user uploads an image of a dog or cat.
2. The application resizes the image to 224 × 224 pixels.
3. The image is preprocessed using MobileNetV2 preprocessing.
4. The trained deep learning model analyzes the image.
5. The application displays the predicted class and model score.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Alokdubey-gif/Dog-Cat-Classification.git
```

Navigate to the project directory:

```bash
cd Dog-Cat-Classification
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
